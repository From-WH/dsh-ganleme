# 干了么 (Git Pulse)

DeepSeek Harness 插件：统计各工作区今天、昨天、本周、本月的 git 提交次数与变更行数，一键生成日报、周报、月报。

## 功能

- 侧边栏入口，全页 Dashboard：按仓库展示提交次数、新增/删除行数、活跃作者、提交明细
- 「全部人 / 只看我」双视角：按各仓库的 git 身份严格归属（email 优先），别人不会算进你的日报
- 一键生成日报/周报/月报：**纯文本**（贴进公司 textarea 直接用）或 **Markdown**；**精简/详细**两档；默认只统计自己的提交
- 5 套内置皮肤（默认跟随主题 / 暖阳 / 青竹 / 海雾 / 暗夜），支持上传单张背景图或整个文件夹背景库、每天随机一张
- 夸夸/嘲讽机制：根据今天提交数据在标题下输出锐评，台词池循环内不重复
- 远程更新（可选）：配置 `updatePackage` 后，右上角蓝色下载按钮一键检查并重装最新版

## 安装

在 DeepSeek Harness 的「插件」页添加插件市场索引后，从「发现」页一键安装；或直接安装 npm 包 / Git 仓库 / 本地目录。

## 配置

在插件详情页配置：

| 字段 | 说明 |
|---|---|
| `extraRoots` | 额外扫描的目录（一级子目录中的 git 仓库自动纳入统计） |
| `excludedPaths` | 排除的目录（精确或前缀匹配） |
| `myEmail` / `myName` | 覆盖"自己"的 git 身份（跨机器场景） |
| `updatePackage` | npm 包名；配置后启用右上角自动更新按钮 |
| `updateRegistry` | 版本检查使用的 registry |
