# 干了么 (Git Pulse)

DeepSeek Harness 插件：统计各工作区和项目目录的 git 提交次数与变更行数，一键生成日报、周报、月报。

## 功能

- 侧边栏入口，全页 Dashboard：按仓库展示提交次数、新增/删除行数、活跃作者、提交明细
- 时间范围：今天、昨天、本周（周一起）、本月，或自定义日期范围（最晚到今天，最长 366 天），附「近 7 天 / 近 30 天 / 上周 / 上月」快捷选项
- 「全部人 / 只看我」：按 git 邮箱归属（不区分大小写，可配置多个邮箱），同名的同事不会算进你的日报
- 报告：日报、周报、月报、自定义区间报告；**纯文本**（直接贴进公司系统的文本框）或 **Markdown**；默认只统计自己的提交。选中「昨天」时生成昨日日报
- 报告风格四档：**工作清单**（只留做了什么，去掉 `fix:`/`feat:` 前缀、时间和行数）、**简洁**（工作清单 + 每个仓库的提交次数）、**标准**（加时间、分支、统计行）、**详细**（全部信息，含作者、时间、分支、行数）；风格之上还可以逐项勾选去前缀、行数、时间、作者，并切换序号写法
- 每条提交展示多少可选 20 / 50 / 全部，之前固定 20
- 项目源：工具栏 📁＋ 打开系统目录选择框，把 Harness 工作区之外的项目加入统计
- 5 套皮肤，可上传单张背景图或导入整个文件夹作为背景库，每天随机一张
- 标题下根据今天的提交量给出夸奖或吐槽，同一组台词用完前不重复
- 自动更新：右上角下载图标在有新版本时高亮，点击后重装最新版

## 报告风格

| 风格 | 内容 |
|---|---|
| 工作清单 | 日期、一句总览（只要提交数和仓库数）、按仓库列出做了什么。没有类型前缀、时间、作者、行数 |
| 简洁 | 工作清单 + 每个仓库的提交次数，总览里带行数 |
| 标准 | 加回统计范围、章节标题、每仓库统计行、提交时间和分支 |
| 详细 | 全部信息：作者、时间、分支、行数 |

风格只是默认组合，弹窗里还能单独开关：去掉 `fix:`/`perf:` 前缀、显示变更行数、显示提交时间、显示提交人。显示提交人在「只看我」下也会生效。选择的风格和条数会记住，下次打开沿用。

### 序号写法

纯文本格式下，每条提交前面的标记可选：`- 横线`、`• 圆点`、`1. 数字`、`1）括号`、`一、中文`、`无序号`。默认：工作清单用横线，其余风格用数字。

- 编号在每个仓库里从 1 重新开始
- 只有一个仓库有条目时不显示仓库标题，条目直接顶格，读起来就是一份清单
- Markdown 只认 `1.` 和 `-`，选了其他标记会退回横线

去掉前缀时只认真正的类型标签（conventional commits 的 `feat`/`fix`/`perf`… 和常见的 `修复:`/`新增:` 等），所以 `API: add endpoint` 这类会原样保留。

## 统计口径

- **按作者时间计日期**：提交算在写代码的那天。rebase、amend、cherry-pick 不改作者时间，所以不会把旧工作算成今天，也不会让它从日报里消失
- **统计所有本地分支**：没合并的功能分支上的工作也会出现；同一个提交在多个分支上只算一次
- **不计 merge 提交**：merge 不是新写的代码
- 读取的提交数达到 `commitLimit` 时，仓库卡片标注「可能不完整」

以上都可以在配置里调整，见下表。

## 安装

在 DeepSeek Harness 的「插件」页添加市场索引：

```
https://raw.githubusercontent.com/From-WH/dsh-ganleme/main/index.json
```

然后在「发现」页一键安装；也可以直接安装 npm 包 `dsh-ganleme`。

## 配置

在插件详情页配置：

| 字段 | 默认 | 说明 |
|---|---|---|
| `extraRoots` | `[]` | 额外统计的目录；也可以用工具栏 📁＋ 添加 |
| `scanDepth` | `1` | 在目录下向下找仓库的层数（1–3） |
| `excludedPaths` | `[]` | 排除的目录，支持 `~` 和符号链接 |
| `myEmails` | `[]` | 你的所有 git 邮箱（工作、个人），不区分大小写；不填则用各仓库的 `user.email` |
| `myEmail` / `myName` | `''` | 旧的单个身份设置，仍然有效 |
| `allBranches` | `true` | 统计所有本地分支；关掉则只看当前分支 |
| `includeMerges` | `false` | 是否统计 merge 提交 |
| `commitLimit` | `5000` | 每个仓库每次最多读取的提交数 |
| `gitConcurrency` | `6` | 同时读取的仓库数 |
| `cacheMs` | `60000` | 统计结果缓存时长（毫秒） |
| `updatePackage` | `dsh-ganleme` | 自动更新检查的 npm 包名；留空则关闭 |
| `updateRegistry` | `https://registry.npmjs.org/` | 版本检查使用的 registry |

## 自动更新说明

- 更新时先卸载再安装新版本；新版本安装失败时会重新装回旧版本，并在页面上显示失败原因
- 从本地目录链接安装（`link:`）的开发版本不会被自动更新覆盖
- Harness 默认有发布冷却期（`minimumReleaseAge`），刚发布的版本可能暂时装不上，页面会显示原因，稍后再试即可
- 没有插件管理服务的部署里，下载图标不显示
